# BeeSafe AI — Streamlit application

A polished local Streamlit interface for the BeeSafe AI research model. It accepts a SMILES string, calculates RDKit molecular features, generates a model estimate for the ApisTox-defined binary acute honeybee-toxicity label, and reports nearest-reference Morgan fingerprint similarity when Phase 03 artifacts are present.

## 1. Place the app in the project

Copy this entire `app` folder into:

```text
E:\CODE\Python\ALL Project\Machine Learning\BeeSafe AI\app\
```

The expected project tree is:

```text
BeeSafe AI/
├── app/
│   ├── app.py
│   ├── beesafe_engine.py
│   ├── requirements.txt
│   └── .streamlit/config.toml
├── data/
│   ├── raw/dataset_final.csv
│   └── processed/phase03/
│       ├── 03_baseline_features.npz
│       └── 03_baseline_metadata.csv
├── models/
│   ├── 08_sigmoid_calibrated_ensemble.joblib
│   └── 05_advanced_tuned_candidate.joblib
└── reports/
```

The app prefers the Phase 08 calibrated ensemble. If it is unavailable, it will try the Phase 05 model and label that fallback as uncalibrated. The Phase 03 feature matrix and metadata provide the molecular-reference context. Predictions can still be made without the reference files, but similarity warnings will be unavailable.

## 2. Run it

Open **Anaconda Prompt** or **Git Bash** in the project root. Use your existing environment; do not create a new Conda environment.

```bash
cd "E:/CODE/Python/ALL Project/Machine Learning/BeeSafe AI"
python -m pip install -r app/requirements.txt
python -m streamlit run app/app.py
```

If the current environment already has the compatible scientific dependencies, you can install Streamlit only:

```bash
python -m pip install streamlit
```

Open the local URL printed by Streamlit (typically `http://localhost:8501`). Use the same Python environment that was used to create the saved model artifact, because scikit-learn/joblib model compatibility can depend on package versions.

## 3. What the app provides

- SMILES validation and canonicalization using RDKit.
- Inference with the saved Phase 08 calibrated ensemble; Phase 05 model is a clearly marked fallback.
- Molecular formula, molecular weight, LogP, TPSA and 12 Phase 03 molecular descriptors.
- Morgan radius-2, 2,048-bit fingerprint generation.
- Maximum Tanimoto similarity against Phase 03 baseline reference structures, when available.
- Adjustable exploratory classification threshold and low-similarity warning cutoff.
- Downloadable per-molecule JSON summary.
- A model/project status page and clear limitations.

## Scientific and safety notes

This is a research prototype. Its output is a prediction of the dataset-defined binary acute honeybee toxicity label. It does **not** directly predict pesticide exposure, colony decline, field risk, or ecological harm, and is not a regulatory safety assessment. The score may not be calibrated for genuinely novel chemical space. The similarity warning cutoff is a heuristic and is not a validated applicability-domain boundary. A structure match to the Phase 03 reference set means the compound may already be represented in the model-development corpus; it is not independent validation.

The app does not retrain the model, alter data, claim external validation, or modify any phase output files. Load only trusted local `joblib` artifacts generated by this project.
